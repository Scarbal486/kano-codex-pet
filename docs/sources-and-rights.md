The production workspace contains 32 single-frame GIF files used only as private visual references. They define the target sticker style, character proportions, palette, clothing, expressions, and accessory placement.

## Publication gate

The repository remains private during production. Making it public, submitting it to a pet gallery, or otherwise redistributing the derivative character artwork requires a new source-and-rights review and explicit user approval. This repository does not grant a license to third-party character assets.
